      Koneksi terbit

      Situs ini tidak punya server. Tombol Terbitkan menyimpan menu langsung ke GitHub, tempat file situs disimpan. Situs akan menampilkan menu baru dalam satu sampai dua menit.

      Cara membuat kunci GitHub (sekali saja, 3 menit)
      1. Buka github.com/settings/personal-access-tokens/new dan masuk ke akun GitHub kamu.
      2. Isi nama bebas, misalnya Admin Dapur Ziham. Pilih masa berlaku, misalnya 1 tahun.
      3. Di Repository access, pilih Only select repositories, lalu pilih repo situs ini.
      4. Di Permissions, buka Repository permissions, cari Contents, ubah jadi Read and write.
      5. Tekan Generate token, salin kodenya, lalu tempel di kolom Kunci GitHub di bawah.

      Kunci hanya disimpan di browser perangkat ini. Jangan bagikan ke siapa pun.

      Cadangan manual

      Tanpa GitHub, kamu tetap bisa mengunduh file menu lalu menaruhnya di folder data/ situs saat upload ke hosting.
